# 表情标签修复

独立的 MaiBot SDK 2.x 插件，不修改麦麦核心、表情选择插件或智能分段插件。

## 行为

- 识别模型回复句末的 `[表情包: 得意,傲娇,叉腰,开心]`，兼容中文冒号。
- 在智能分段前清理标签，使用现有表情库情绪标签查询真实图片，不额外调用 LLM。
- 每次回复最多附一张图片。分段启用时，图片放在首段文字之后；剩余文字继续由原分段插件投递。
- 纯标签回复转换为真实图片消息；找不到图片时中止该空消息，不发送标签。
- 普通正文保留；引用、代码块、行内代码、Markdown 引用及明显的格式讨论保留。
- 不转换普通括号动作，不强制每句话配图，不保证模型从不生成其他形式的占位文字。
- 已附图片或表情的消息不会额外加图。
- 图片交由宿主现有发送链处理，本插件不重试发送，避免重复图片。

## 使用

将目录放入实例 `plugins/local_emoji-label-guard`，在插件页启用“表情标签修复”。
配置 `[plugin].enabled = false` 或在 WebUI 关闭，即可停止。
需要表情库已经收录并注册图片，无需知道文件名或创建关键词规则。

插件只依赖宿主提供的 SDK、pydantic 及标准库，没有额外第三方依赖。
源代码与反馈：https://github.com/hhucz/maibot-emoji-label-guard 。许可证：MIT。

已验证环境：MaiBot 1.3.12、SDK 2.15.0、Python 3.12。

## 测试

安装开发依赖并运行：

```bash
python -m pip install -r requirements-dev.txt
python -m unittest discover -p test_plugin.py -v
```

普通环境运行 SDK 与模拟接口测试；位于本地 MaiBot 工作区时，额外运行宿主 manifest 和图片解码集成检查。所有测试不向 QQ 群发消息。
包含 20 项回归测试，并执行宿主原生二进制组件解码函数检查图片载荷。

## 限制

只处理句末、结构明确的标签，避免把普通正文或示例误认为发图请求。
引用保护是保守的文本规则，含糊的自然语言引用仍可能无法完全识别。
若宿主其他插件在后续阶段又生成新标签，或发送前改写了正文导致无法关联图片，可能需要后续适配。
更新其他插件通常不会覆盖本插件；宿主 Hook 协议发生变化时仍需适配。
